键位提示 v1.0.0
========================================

一个常驻托盘的打字键位提示小工具，支持搜狗双拼和 86 版五笔。

【运行】
双击 ShuangpinHint.exe 即可，无需安装。
首次运行后托盘区会出现一个小键盘图标。

【怎么用】
· 自动模式（默认）：中文打字时，悬浮窗自动贴在光标上方，
  显示当前按键；打完自动收起，不挡视线。
· 始终显示：悬浮窗常驻屏幕。右上角的 × 可以临时收起，
  再次打字又会自动出现。
· 敲字母时对应键帽会高亮。

【切换】
右键托盘图标：
  双拼提示 / 五笔 86 提示   选一种键位表
  自动 / 始终显示           选显示方式
  开机自启
  关于                      版本、作者、赞赏码
  退出

双击托盘图标 = 在"自动"和"始终显示"之间快速切换。

【配置文件】
%APPDATA%\ShuangpinHint\settings.ini
删除这个文件即可恢复默认（自动 + 双拼）。

【系统要求】
Windows 7 / 8 / 10 / 11，需要 .NET Framework 4.5 或更高
（Win10、Win11 系统已自带，无需另外安装）

【说明】
这是输入法的辅助提示工具，本身不是输入法，也不拦截、不改写你输入的内容，
只是根据你敲的键把对应的声母/韵母或五笔字根显示出来。
